How to read this data

What counts as a page view

A page view is one successful HTML page load served through the site's edge worker. Reloads count again; in-page anchor jumps and asset requests do not. Requests that do not return HTML are ignored.

How visitors are estimated

Each request is reduced to a one-way hash of a secret salt, the current UTC date and the requesting IP address. The IP address itself is never written to storage. Because the date is part of the input, the hash changes every day and cannot be used to follow anyone across days. The visitor count is therefore an estimate of distinct visitors within a day, not an identity count, and it will overstate shared networks and understate people using several networks.

How bots are classified

Traffic is labelled as a bot when the user-agent string matches known crawlers, preview fetchers and headless browsers. Headline figures show human traffic only; bot volume is reported separately so crawler activity is never mistaken for scholarly or public interest. Classification relies on self-reported user-agents, so it is indicative rather than exact.

How actions, paths and exits are measured

A small first-party script records outbound link clicks, file downloads, same-site page-to-page movements and visit endings. It sends only the event type, the current path, the previous path where relevant, and an outbound domain or file path. It respects the browser's Do Not Track setting, and events are accepted only when they originate from this site.

How return visits are estimated

Return visits use a single local browser flag that records only whether this browser has been here before. The flag never leaves the browser; only the resulting yes/no value is sent with a visit event. No reusable visitor identifier exists, so this figure counts returning visits rather than returning people, and it resets whenever site data is cleared.

Location precision and retention

Location is recorded at country level only, as supplied by the edge network. No city, region, coordinates, IP address or raw request log is stored. Only the aggregated event rows shown on this page are retained, and comparison figures use the equivalent period immediately preceding the selected range.

What is deliberately excluded

There is no demographic or interest profiling, no cross-site tracking, no third-party analytics or advertising code, no precise location, and no conventional bounce-rate modelling.
